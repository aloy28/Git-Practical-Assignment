## Purpose of the Repository

The purpose of this repository is to demonstrate the basic concepts and practical usage of Git and GitHub. It contains the files and activities completed as part of the Basic Toolkit for Research practical.

## Objectives

* To understand the basics of Git and GitHub.
* To learn how to create and manage a Git repository.
* To understand the process of staging and committing files.
* To learn how to connect a local Git repository with GitHub.
* To understand how to push files from a local repository to GitHub.
* To learn how to clone a GitHub repository.
* To understand how to track and manage changes using Git.
